为什么选择 IELTS Free

把「学习」这件事交还给你和设备，而不是服务器。以下是这个项目的六条底线。

完全免费

没有付费墙、没有广告、没有内购。全部功能与内容随安装包提供，永久可用。

完全离线

核心学习流程不联网。Android 正式版甚至不申请 INTERNET 权限，飞行模式下也能完整使用。

开源

源代码以 MIT 许可发布，构建可复现、数据层可审计，欢迎任何人贡献代码、内容与翻译。

无账号

无需注册或登录，游客模式直接开始。你的学习画像保存在本机，不需要手机号或邮箱。

无 AI

不依赖任何在线大模型。自适应算法、记忆排程与解析全部在本地运行，断网也照常工作。

无服务器

没有后端、没有云同步。学习进度只存在你的设备上，我们无法读取，也不会收集任何数据。

功能一览

覆盖雅思四项技能与完整的学习闭环：学 → 练 → 错 → 复盘 → 能力更新 → 下一次训练自动变化。

词汇

300 个雅思核心词，L0–L6 间隔记忆（4h / 1d / 3d / 7d / 14d / 30d / 60d），七种练习题型，含音标、搭配、雅思写作与口语用法及例句。

300 词 · L0–L6 记忆

阅读

8 篇原创文章、80 道题，涵盖 True/False/Not Given、单选与摘要填空。每题都附带证据、关键词、同义替换、逻辑与解析。

8 篇 · 80 题

听力

精听六步闭环：盲听 → 逐句听写 → 对照原文 → 分类错因 → 影子跟读 → 整段复听。音频由设备 TTS 本地合成，内容包不含任何音频文件。

精听六步 · 设备 TTS

口语

Part 1/2/3 真实计时（Part 2 含 60 秒准备 + 120 秒作答）、题卡、笔记、录音回放与五项自评。刻意不做 AI 打分。

Part 1/2/3 · 录音自评

写作

计时写作与实时字数统计（兼容中英混排），Task 1 折线/柱状/饼图与表格，范文对照含段落提纲与标注高亮，另附句型库。

计时 · 范文 · 句型库

错题本

每一道错题自动收集，按错因分类并可筛选、查看详情、反复重做，直到真正掌握为止。

自动收集 · 分类复练

自适应引擎

能力评分、训练优先级、难度调整、记忆排程、连胜追踪与每日计划，全部本地运行、单元测试覆盖。

本地算法

学习统计

累计学习概览、五维能力雷达与预测分数，并附听力错因分布，让每一次进步都看得见。

五维雷达 · 预测分数

注意：APK 目前使用 debug 签名。 安装时 Android 会提示「未知来源 / 未知开发者」，这是正常的——本项目尚未启用正式签名密钥。
  • 下载后可用 Releases 中的 SHA256SUMS.txt 校验文件完整性，例如 Get-FileHash .\IELTS-Free-Android-*.apk -Algorithm SHA256。
  • 也可以从源码自行构建：flutter pub get 后执行 flutter build apk --release。
