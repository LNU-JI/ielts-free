# 词汇主题分类（Vocabulary topics）

> 本文件是**共享契约**，内容生产与 UI 两侧都必须严格按这 40 个 slug 取值，
> 不得自行新增、改名或使用中文作为键。
>
> 用途：
> 1. `vocabulary_topics.topic` 列的取值域（内容库，只读）
> 2. 每个主题对应一张插图 `assets/illustrations/<slug>.webp`
> 3. 词汇本的分类浏览与筛选

## 约束

- **一个词可以属于多个主题**（`vocabulary_topics` 是多对多），但**至少一个**。
- 主题 slug 是**英文**，UI 展示时用中文名（上表第 3 列），中文名放 `AppStrings` 或 UI 层映射表，**不要写进数据库**。
- 插图文件命名严格等于 slug：`assets/illustrations/education.webp`。
