## 二、机制蒸馏：五个层次

### 层 1 · 记忆调度（决定「什么时候复习」）

这是所有背单词产品的**真正分水岭**——界面可以抄，调度算法不能。

| 代际 | 代表 | 机制 | 缺陷 |
| --- | --- | --- | --- |
| L1 固定间隔 | Leitner 盒子 | 5 个盒子，答对进一格，答错回第一格 | 无记忆模型，间隔完全预设 |
| L2 简单倍数 | **SM-2**（1987） | `I(n) = I(n-1) × EF`，单一难度因子 | 「难度地狱」：EF 只降不升，卡片越来越难 |
| L3 半衰期回归 | Duolingo HLR（2016） | `log(h) = 截距 + w·√(正确数) + w·√(错误数) + w·难度` | 平面回归，不追踪单卡状态轨迹 |
| L4 马尔可夫决策 | 墨墨 DHP / SSP-MMC（KDD 2022） | 把调度建模为 MDP，随机最短路径求解 | 需服务端算力 |
| **L5 三组件模型** | **FSRS-6**（Anki 内置） | DSR 模型 + 幂律遗忘曲线 + 21 参数端到端训练 | —— |

#### FSRS-6 的关键设计（可直接迁移）

**DSR 三组件**，完整描述一条记忆：

| 变量 | 含义 | 范围 | 是否落盘 |
| --- | --- | --- | --- |
| **R** 可提取性 | 此刻能回忆起的概率 | [0,1] | 否，由 S 和 t 实时算出 |
| **S** 稳定性 | R 从 100% 衰减到 90% 所需天数 | [0,∞) | 是 |
| **D** 难度 | 材料内在难度 | [1,10] | 是 |

**幂律遗忘曲线**（v4 起，优于指数）：

```
R(t, S) = (1 + FACTOR × t/S)^DECAY      DECAY = -0.5, FACTOR = 19/81
```

**复习间隔**：

```
I(r_d, S) = (S / FACTOR) × (r_d^(1/DECAY) - 1)
```

**四个最有价值的机制**（都比当前实现强）：

1. **间隔效应**：`e^(w₁₀×(1-R)) - 1` —— R 越低（越接近遗忘）复习收益越大。最优复习点不是 R=100%，而是 **R≈30-40%**。当前的固定 L0-L6 完全没建模这一点。
2. **难度均值回归**：`D'' = w₇×D₀(4) + (1-w₇)×D'` —— 根本性解决 SM-2 的「难度地狱」。当前实现**根本没有难度维度**。
3. **遗忘后部分保留**：`(S+1)^(w₁₃)` —— 遗忘不是重置归零。当前实现答错直接降级。
4. **稳定性饱和**：`S^(-w₉)` —— 越熟的卡片收益递减，避免过度复习。

**实测收益**：同等记忆效果下**减少 20-30% 复习量**；FSRS-6 在 **99.6% 的用户上优于 SM-2**。

> **Dart 已有实现**（`dart-fsrs`，v4.5），可直接引入或按论文自实现 v6 的 21 参数版本。

### 层 2 · 训练方法（决定「怎么练」）

界面可以抄，**方法论才是产品壁垒**。以下是从雅思专项产品中蒸馏出的完整训练闭环。

#### 2.1 听力精听八步闭环（Voxall 方法论）

```
选材(1-3分钟) → 盲听/做题(不暂停不查词) → 逐句听写或挖空(每句最多3-5遍)
→ 对照原文分类错因 → 生词入词本 + 难句入句子收藏
→ 断句跟读 → 脱离原文跟读 → 录音自评 → 整段复听(不看原文验证)
```

**核心洞察：听写只是第一步，错因分类才是精听的关键。**

蒸馏出的**听力错因五分类**（可直接做成交互选项）：

| 错因 | 含义 | 对应的补救动作 |
| --- | --- | --- |
| 生词型 | 词不认识，或只知道中文不知道发音 | 入生词本（带原句+发音+场景） |
| 语音型 | 连读、弱读、吞音、爆破、重音、口音 | 难句收藏 → 跟读模仿 |
| 拼写型 | 听出来了但拼错（双写、单复数） | 拼写专项 |
| 理解型 | 词都听到了但没听懂结构/因果/转折/指代 | 长难句拆解 |
| 题目对应型 | 听懂了但没发现同义替换/干扰项 | 同义替换专项 |

**其他可迁移细节**：
- 同一处**最多听 3-5 遍**，超了就标记看原文（避免制造错误的听觉记忆）
- **挖空精听**比全文听写轻，更适合与题目复盘结合
- 跟读**分三轮**：看原文断句跟读 → 脱离原文连续跟读 → **录音对比原音**
- 收藏的资产要带**三要素**：原句、发音、场景

#### 2.2 词汇训练（国内产品差异化的地方）

| 产品 | 独有机制 | 可迁移性 |
| --- | --- | --- |
| 百词斩 | **图片联想记忆**（一图一词） | 需图片资源，离线可做 |
| 墨墨 | **记忆算法 + 每日上限**（复习量封顶，防止劝退） | ✅ 高 |
| 扇贝 | **词根词缀 + 例句 + 打卡小组** | 词根词缀可做 |
| 不背单词 | **真实语境例句**（影视/新闻原句）+ 发音 | ✅ 高，需语料 |

**当前已覆盖**：词义、音标、词性、搭配、雅思用法、例句、七种题型、拼写容错
**缺失**：词根词缀、图片联想、听音辨义、例句听写、近义辨析、词频分级

#### 2.3 口语与写作（当前完全缺失）

| 模块 | 竞品做法 | 离线可行性 |
| --- | --- | --- |
| 口语 | 跟读 + **录音对比原音**（Cake/ELSA 的发音打分需 AI） | ✅ 录音对比可离线；打分需 AI ❌ |
| 口语 | Part 1/2/3 **题库 + 计时 + 提纲卡** | ✅ 完全可离线 |
| 口语 | 影子跟读（羊驼雅思主打） | ✅ 可离线（复用听力音频） |
| 写作 | Task 1/2 **句型库 + 范文 + 结构模板** | ✅ 可离线 |
| 写作 | **计时写作 + 字数统计 + 提纲生成** | ✅ 可离线 |
| 写作 | AI 批改 | ❌ 与「无 AI」定位冲突 |

### 层 3 · 动机系统（决定「会不会坚持」）

Duolingo 的核心结论：**留住第 1 天的机制，和留住第 6 个月的机制，完全不同**。

| 机制 | 服务阶段 | 关键数据 | 离线可行性 |
| --- | --- | --- | --- |
| **XP 经验值**（通用货币） | 全程 | 串联 streak/等级/成就，一次学习同时推进多条进度 | ✅ |
| **每日目标**（用户自定义） | Day 1 | 目标必须可达，否则损失厌恶机制失效 | ✅ |
| **连胜 + 冻结道具** | Day 7+ | 有冻结：第 14 天平均 streak **30.6 天** vs 无冻结 **18.9 天** | ✅ |
| **成就双档**（个人纪录 / 里程碑） | Day 1 + 长期 | 14 天留存随成就难度**单调上升**：32.3% → 74.2% | ✅ |
| **30 人小联赛**（非全球榜） | 中期 | 竞技窗口要小到「多数人觉得能赢」 | ⚠️ 无账号则只能用**本地虚拟对手/历史自己** |
| 好友连胜 | 长期 | 社会问责比排名更持久 | ❌ 与无账号冲突 |
| 限时活动/任务 | 中期 | 制造 streak 给不了的紧迫感 | ✅ 可本地化 |

**当前只有 streak，且无冻结、无 XP、无成就、无每日目标** —— 动机系统基本空白。

## 三、差距矩阵

| 维度 | IELTS Free V0.1 | 竞品基准 | 差距 | 离线可行 |
| --- | --- | --- | --- | --- |
| **技能覆盖** | 词汇 + 阅读 | 听说读写全科 | 🔴 **严重** | ✅ |
| **记忆算法** | 固定 L0-L6 间隔 | FSRS-6（21 参数） | 🔴 **严重** | ✅ |
| **动机系统** | 仅 streak | XP/成就/联赛/任务/冻结 | 🔴 **严重** | ✅（联赛需变通） |
| **数据反馈** | 无统计页 | 报告 + 雷达 + 预测分 | 🔴 **严重** | ✅ |
| **听力训练** | 无 | 精听八步 + 错因分类 | 🔴 **严重** | ✅ |
| **口语训练** | 无 | 题库 + 跟读 + 录音 | 🔴 **严重** | ✅（打分需 AI） |
| **写作训练** | 无 | 句型库 + 范文 + 计时 | 🔴 **严重** | ✅ |
| **词汇深度** | 词义/音标/搭配/例句 | + 词根词缀/图片/听音 | 🟡 中等 | ✅ |
| **工具** | 无 | 划词查词/句子收藏 | 🟡 中等 | ✅ |
| **内容量** | 300 词 / 8 篇 | 数千词 / 数百篇 | 🟡 中等 | ✅（生产问题） |
| 云同步 | 无（**有意不做**） | 有 | ⚪ 定位差异 | ❌ |
| AI 批改 | 无（**有意不做**） | 有 | ⚪ 定位差异 | ❌ |

**结论**：功能缺口集中在 **听说写三科 + 记忆算法 + 动机系统 + 数据反馈** 四大块，
且**全部可以离线实现**，与「无账号、无服务器、无 AI」的产品定位不冲突。

## 五、与产品定位的冲突提示（必须守住）

本产品的三条红线是 **离线 / 无账号 / 无 AI**。以下竞品机制**不可照搬**：

| 竞品机制 | 冲突点 | 离线替代方案 |
| --- | --- | --- |
| 好友连胜、全球排行榜 | 需账号与服务器 | 用**历史自己**做对手（「上周的你」），或本地虚拟对手 |
| AI 口语打分 / 写作批改 | 违反无 AI 定位 | **录音对比原音** + 自评清单（发音清晰度/节奏/停顿） |
| 云同步 | 需服务器 | 保留现有「数据导出」，可选加「本地文件导入导出」 |
| 付费解锁词库 | 违反永久免费 | 全部内容随包发布 |

## 六、建议的第一步

**先做 P0 的第 1、3 项（听力模块 + 统计页）**，理由：

1. 听力是雅思四大科中**当前完全空白**的一科，补上后产品从「半个 App」变成「完整备考工具」
2. 统计页**工作量小、感知强**，能立刻让已有功能（词汇/阅读/错题）的价值被用户看见
3. 两者都不依赖外部资源，纯本地实现

FSRS 升级（P0-2）建议**紧随其后单独做**——它要改动现有数据表结构并迁移用户已有复习进度，
需要谨慎设计和充分测试。
